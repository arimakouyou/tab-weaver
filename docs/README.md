## 🎯 使用ガイドライン

### 初回学習パス
```
1. README.md (10分)
   ↓ 拡張機能の概要理解
2. INDEX.md (5分)
   ↓ ドキュメント構造把握
3. 対象者別ドキュメント (30-60分)
   ↓ 深い理解
4. 実践・開発 (∞)
```

### 日常開発での活用
- **API確認**: [API.md](./API.md) でメソッド仕様確認
- **設計判断**: [COMPONENT_SPECS.md](./COMPONENT_SPECS.md) で設計パターン参照
- **セキュリティ**: [SECURITY_GUIDE.md](./SECURITY_GUIDE.md) でチェックリスト確認
- **トラブルシューティング**: [DEVELOPMENT_GUIDE.md](./DEVELOPMENT_GUIDE.md) で解決方法検索

### ドキュメント貢献
```bash
# 新しいドキュメント作成
mkdir -p docs/
touch docs/NEW_FEATURE_GUIDE.md

# 既存ドキュメント改善
git checkout -b docs/improve-security-guide
# 編集・コミット・プルリクエスト
```
